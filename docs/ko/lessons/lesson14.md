# 제14강 작품 완성과 영상 촬영

## 이번 강의의 목표

- 시제품을 개선해 작품을 완성한다
- 작품의 영상을 촬영한다
- 작품 개요 문서를 작성한다

---

## 이번 강의의 작업

### 1. 시제품 개선

지난번 동작 검증에서 발견한 문제점을 수정합니다.

- 부품을 다시 설계・출력해야 한다면 서둘러 착수합시다
- 미세 조정으로 해결할 수 있다면 줄이나 드릴로 대응합니다

### 2. 마무리・장식

작품의 완성도를 높이기 위한 마무리 작업을 합니다.

| 시도 | 방법 |
|------|------|
| **표면 처리** | 사포질, 퍼티 메움 |
| **도색** | 아크릴 물감, 스프레이 도료 |
| **장식** | 스티커, 테이프, 천, 종이 등 이종 재료 활용 |
| **받침대 정비** | 받침대를 깔끔하게 마무리하고 안정성을 확보 |

::: tip 평가 요점 「완성도」
표면 처리・도색・장식・이종 재료 활용 등의 시도는 평가의 「완성도」에 포함됩니다. 시간이 허락하는 한 마무리에 공을 들입시다.
:::

### 3. 영상 촬영

작품이 움직이는 모습을 영상으로 촬영합니다.

1. **밝은 곳**에서 촬영합니다
2. 작품 전체가 나오도록 **삼각대나 스마트폰 거치대**를 사용하면 안정적입니다
3. 다음 내용을 포함해 주세요:
   - 작품의 전체 모습
   - 핸들을 돌려 기구가 움직이는 모습
   - 특별히 공들인 부분의 클로즈업
4. 영상 길이는 **30초〜1분 정도**가 기준입니다

### 4. 작품 개요 문서 작성

다음 내용을 포함한 문서(Word나 Google 문서 등)를 작성합니다.

- **작품명**
- **콘셉트**: 어떤 발상・비유로 작품을 만들었는가
- **사용한 기구**: 기어, 캠, 요동 크랭크 등
- **공들인 부분**: 설계・조형・마무리에서 신경 쓴 점
- **어려웠던 점과 해결 방법**
