## 1. 부품의 구성요소화

### 본체와 구성요소의 차이

지금까지는 **본체(Body)**를 만들어 형태를 만들어 왔지만, 여러 부품이 서로 움직이는 구조(기어끼리 맞물리는 등)를 설계하려면 부품을 **구성요소(Component)**로 만들어야 합니다.

| | 본체 | 구성요소 |
|---|---|---|
| 용도 | 하나의 부품 안에서의 형상 | 독립된 부품으로 다룸 |
| 이동 | 다른 본체와 연동 | 개별적으로 이동・회전 가능 |
| 조인트 | 사용 불가 | 사용 가능 |

::: tip 구성요소의 이미지
구성요소는 컴퓨터의 **폴더**와 비슷합니다. 부모 구성요소 안에 자식 구성요소, 그 안에 또 손자 구성요소처럼 계층을 만들 수 있어 부품이 많아져도 정리하기 쉽습니다.
:::

### 스케치에서 구성요소 만들기

![구성요소 만들기](/images/lesson09/component-creation.jpg)

1. `1. 부품의 구성요소화.f3d`를 엽니다
2. 미리 준비된 스케치를 클릭하고 **돌출**(단축키: **E**)을 실행합니다
3. 여기가 중요합니다: 작업 드롭다운을 **「새 본체」가 아니라 「새 구성요소」**로 변경합니다
4. 상판을 **5 mm**로 돌출하고 구성요소 이름을 「상판」으로 바꿉니다

### 다리 만들기(구성요소 복사)

상판과 마찬가지로 다리 스케치에서 **새 구성요소**로 돌출합니다(높이 **50 mm**).

다리를 4개 만들려면 **복사**를 사용하는데, 여기에 중요한 차이가 있습니다:

![구성요소 복사](/images/lesson09/component-copy.jpg)

| 복사 방법 | 조작 | 특징 |
|---|---|---|
| **이동/복사** | 마우스 오른쪽 버튼 → 이동/복사 → 「복사본 만들기」 ON | 원본과 항상 **동기화**됩니다(한쪽을 수정하면 다른 쪽도 바뀜) |
| **복사하여 붙여넣기** | 복사 → 마우스 오른쪽 버튼 → **새로 붙여넣기** | 완전히 **독립된** 복사본(한쪽을 수정해도 다른 쪽에 영향 없음) |

::: warning 동기화 복사에 주의
「이동/복사」로 만든 구성요소는 한쪽에 구멍을 뚫으면 다른 쪽에도 구멍이 뚫립니다. 같은 부품을 여러 개 쓸 때는 편리하지만, 개별적으로 바꾸고 싶다면 「새로 붙여넣기」를 사용하세요.
:::

## 2. 조인트(강체)

### 보텀업 방식과 톱다운 방식의 설계

| 접근법 | 설명 | 적합한 상황 |
|---|---|---|
| **보텀업 방식** | 개별 부품을 먼저 설계하고 나중에 조립 | 범용 부품의 재사용, 대규모 조립체 |
| **톱다운 방식** | 조립체 전체 안에서 각 부품을 설계 | 부품 간 위치 관계가 밀접한 설계 |

이번에는 보텀업 방식으로, 먼저 부품을 만들고 **조인트**로 조립하는 접근법을 배웁니다.

### 강체 조인트로 테이블 조립하기

`2. 조인트 강체.f3d`를 엽니다. 상판과 다리 4개가 분리된 상태입니다.

![조인트의 스냅점 지정](/images/lesson09/joint-rigid-snap.jpg)

1. **조립 → 조인트**를 선택합니다
2. 먼저 **움직일 쪽**(다리)의 스냅점을 클릭합니다
3. 다음으로 **목적지**(상판의 모서리)의 스냅점을 클릭합니다
4. 유형이 **강체**로 되어 있는지 확인하고 **확인**으로 확정합니다

![테이블 조립 완료](/images/lesson09/table-assembly.jpg)

### 스냅점 지정 요령

- **면을 클릭** → 그 면의 중심에 스냅
- **모서리를 클릭** → 모서리의 중점에 스냅
- **꼭짓점을 클릭** → 꼭짓점에 스냅

::: tip Ctrl(Mac: Cmd) 키로 면 고정하기
스냅점을 고를 때 마우스를 움직이면 다른 면으로 바뀌어 버릴 수 있습니다. **Ctrl**(Mac: **Cmd**) 키를 누른 채 면을 클릭하면 그 면의 스냅점 후보가 **고정**되어 고르기 쉬워집니다.
:::

::: tip 「뒤집기」 버튼
부품이 의도와 반대 방향으로 붙어 버렸다면 조인트 설정 화면의 **「뒤집기」** 버튼을 눌러 보세요.
:::

### 연습: 상자 조립

`3. 조인트 강체 연습.f3d`를 엽니다. 6장의 판으로 상자를 조립해 봅시다.

![상자 조립 연습](/images/lesson09/box-assembly.jpg)

**조립 순서의 요령:**
1. 먼저 **좌우 판**을 앞면・뒷면에 붙입니다
2. 다음으로 **뒤쪽 판**을 붙입니다
3. 마지막으로 **위아래 판**을 붙입니다

::: warning 조립 순서에 주의
갑자기 위아래 판부터 붙이려고 하면 좌우 판이 아직 붙어 있지 않아 잘 되지 않습니다. 앞면을 기준으로 좌우를 먼저 붙인 다음 위아래 판을 붙입시다.
:::

앞면・뒷면에는 사각 구멍과 둥근 구멍이 뚫려 있습니다. 나중에 여기에 봉을 끼우므로 **구멍 위치가 앞뒤로 맞도록** 주의해서 조립해 주세요.

## 3. 조인트(회전・슬라이더)

`4. 조인트 회전・슬라이더.f3d`를 엽니다.

### 회전 조인트

**회전 조인트**는 부품이 하나의 축을 중심으로 회전할 수 있게 합니다.

1. **조립 → 조인트**를 선택합니다
2. 회전축이 될 스냅점을 지정합니다
3. 모션 유형을 **회전**으로 설정합니다
4. **확인**으로 확정합니다
5. 부품을 드래그하면 지정한 축을 중심으로 회전합니다

### 슬라이더 조인트

**슬라이더 조인트**는 부품이 직선 위를 미끄러질 수 있게 합니다.

1. **조립 → 조인트**를 선택합니다
2. 슬라이드 방향을 정할 스냅점을 지정합니다
3. 모션 유형을 **슬라이더**로 설정합니다
4. **확인**으로 확정합니다

### 모션 제한 설정

![슬라이더의 모션 제한](/images/lesson09/slider-motion-limit.jpg)

조인트의 가동 범위를 제한해 부품이 의도한 범위에서만 움직이게 할 수 있습니다.

1. 브라우저 패널이나 타임라인에서 조인트 아이콘을 **더블 클릭**(또는 마우스 오른쪽 버튼 → **조인트 편집**)
2. **모션** 탭에서 다음을 설정합니다:
   - **최솟값**: 가동 범위의 하한(예: **-23 mm**)
   - **최댓값**: 가동 범위의 상한(예: **-4 mm**)
3. **제한 미리보기**로 확인하면서 값을 미세 조정합니다
4. **확인**으로 확정합니다

::: tip 값의 미세 조정
처음부터 딱 맞는 값을 내기는 어렵습니다. 「제한 미리보기」를 사용하면서 값을 조금씩 바꿔 스토퍼의 위치와 정확히 맞도록 해 봅시다.
:::

### 부품 고정(핀 기능)

조인트를 조작하는 도중에 움직이지 않았으면 하는 부품이 움직여 버릴 때가 있습니다.

![핀 고정 기능](/images/lesson09/pin-fix.jpg)

- 구성요소를 마우스 오른쪽 버튼으로 클릭 → **고정(핀)**을 선택하면 그 부품이 완전히 고정됩니다
- 핀으로 고정한 부품과 강체 조인트로 연결된 부품도 함께 고정됩니다
- 해제하려면 다시 마우스 오른쪽 버튼 클릭 → **고정 해제**

### 연습: 상자・회전봉・슬라이드봉・스토퍼 조립

![회전・슬라이더 연습 목표](/images/lesson09/rotation-slider-goal.jpg)

`5. 조인트 회전・슬라이더 연습.f3d`를 엽니다. 다음을 조립해 봅시다:

1. **상자**를 강체 조인트로 조립합니다(복습)
2. **사각 봉**의 양 끝에 스토퍼(T자 부품)를 강체 조인트로 붙입니다
3. 사각 봉을 **슬라이더 조인트**로 상자에 붙이고 모션 제한을 설정합니다
4. **둥근 봉**에 스토퍼를 강체 조인트로 붙입니다
5. 둥근 봉을 **회전 조인트**로 상자에 붙입니다
6. 완성했으면 각 부품을 움직여 제대로 작동하는지 확인합니다

### 구성요소 색상 구분 표시

부품이 많아져 구별하기 어려워졌다면:

**유틸리티 → 구성요소 색상 표시**를 클릭하면 구성요소별로 자동으로 색이 구분됩니다. 같은 구성요소의 복사본은 같은 색이 되므로 구조를 시각적으로 파악하기 쉬워집니다.

## 4. 모션 스터디

완성한 조립 모델의 움직임을 **자동으로 애니메이션 재생**하는 기능입니다.

![모션 스터디](/images/lesson09/motion-study.jpg)

1. **조립 → 모션 스터디**를 선택합니다
2. 애니메이션으로 표시할 조인트를 클릭합니다
3. 타임라인 위에 **점을 추가**하고 각도나 위치 값을 입력합니다
   - 예: 회전 조인트에 **0° → 360°**를 설정
4. **재생** 버튼을 누르면 움직임이 애니메이션으로 표시됩니다
5. **반복 재생**으로 여러 번 확인할 수 있습니다

::: tip 속도 조정
재생이 너무 빠르다면 속도 조정 슬라이더로 늦출 수 있습니다.
:::
