## 이번 강의의 작업

### 1. 작품 구상 구체화하기

1. 어떤 기구(기어・캠・요동 크랭크 등)를 쓸지 정합니다
2. 완성 이미지를 스케치합니다(손으로 그려도 됩니다)
3. 필요한 부품의 목록을 만듭니다
4. 각 부품의 대략적인 치수를 정합니다

::: tip 구상의 요점
- 우선은 **단순한 구성**으로 생각하고, 움직이는 것을 최우선으로 합시다
- 너무 복잡하게 만들면 조립이 어려워집니다
- 기구의 움직임을 무언가 다른 것에 **빗대어** 표현하면 독창성이 높아집니다(예: 기어의 회전 → 행성의 공전)
:::

### 2. 부품 설계

1. Fusion에서 각 부품을 모델링합니다
2. 부품끼리의 **끼워 맞춤**이나 **접합부**의 치수에 주의합니다
3. 3D 프린터로 출력하는 경우:
   - 오버행이 45° 이상이 되지 않도록 궁리합니다
   - 서포트 재료가 필요한 부분을 최소한으로 합니다
4. 레이저 커터로 출력하는 경우:
   - 판 두께에 맞춘 치수 설계
   - DXF 파일 내보내기

### 3. 부품 출력

1. 설계한 부품을 `.stl`(3D 프린터) 또는 `.dxf`(레이저 커터)로 내보냅니다
2. 출력 장비의 조작 절차에 따라 출력합니다
3. 출력한 부품의 치수를 확인하고 필요에 따라 설계를 수정합니다
