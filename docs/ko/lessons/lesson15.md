# 제15강 작품 발표・강평과 전체 정리

## 이번 강의의 목표

- 완성한 작품을 발표한다
- 다른 수강생의 작품을 감상하고 코멘트를 쓴다
- 수업 전체를 되돌아본다

---

## 발표의 흐름

### 1. 작품 발표

한 사람씩 작품을 발표합니다.

**발표 내용(1인당 3〜5분 정도):**

1. **작품명**과 콘셉트 소개
2. **실연**: 작품을 움직여 보여 주기
3. **사용한 기구** 설명
4. **공들인 부분**과 **어려웠던 점**
5. 질의응답

::: tip 발표의 요점
- 작품을 움직이면서 설명하면 전달이 잘 됩니다
- 「왜 이 기구를 골랐는지」「무엇에 빗대었는지」를 이야기하면 독창성이 잘 전해집니다
- 실패나 시행착오의 경험도 공유합시다. 그것도 배움의 일부입니다
:::

### 2. 강평

- 교원의 피드백
- 수강생끼리의 감상・코멘트

### 3. 전체 정리

수업 전체를 되돌아보며 디지털 패브리케이션에서 배운 것을 정리합니다.
