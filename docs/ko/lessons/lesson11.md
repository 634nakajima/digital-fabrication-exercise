## 기구의 종류에 대하여

지난 강의의 기어 기구와 이번 캠 기구 외에도 가라쿠리 작품에 활용할 수 있는 기구는 많습니다.

| 기구 | 특징 |
|------|------|
| **스퍼 기어** | 평행한 축 사이에서 회전을 전달(지난 강의에서 학습) |
| **베벨 기어(우산 기어)** | 직각으로 교차하는 축 사이에서 회전을 전달 |
| **웜 기어** | 높은 감속비를 얻을 수 있음. 역회전 방지 기능이 있음 |
| **랙 앤 피니언** | 회전 운동을 직선 운동으로 변환 |
| **캠 기구** | 회전을 상하 운동으로 변환(이번 강의에서 학습) |
| **슬라이더 크랭크** | 회전을 직선 왕복 운동으로 변환(피스톤 운동) |
| **요동 크랭크** | 회전을 요동 운동으로 변환(이번 강의에서 학습・참고) |

참고: [からくりすと(Karakurist)](https://karakurist.jp/) — 각 기구의 애니메이션을 볼 수 있습니다

## 1. 캠 기구란

**캠 기구**는 회전 운동을 왕복 운동(상하 운동 등)으로 변환하는 기구입니다. 가라쿠리 인형이나 오르골 등에 널리 쓰입니다.

### 캠 기구의 구성

| 부품 | 역할 |
|------|------|
| **캠** | 회전하는 부품. 형상에 따라 운동 패턴이 달라집니다 |
| **종동자(종동절, Follower)** | 캠의 표면을 따라 움직이는 부품. 상하 운동을 출력합니다 |
| **프레임** | 캠과 종동자를 지지하는 구조체 |

### 캠의 종류

| 캠의 형상 | 움직임의 특징 |
|---|---|
| **원판 캠(편심 캠)** | 매끄러운 상하 운동. 가장 단순합니다 |
| **하트형 캠** | 등속으로 상승, 등속으로 하강. 일정한 리듬의 움직임 |
| **달걀형 캠** | 천천히 상승하고 빠르게 하강(또는 그 반대) |
| **부정형 캠** | 자유로운 움직임을 설계할 수 있음. 창작에 적합 |

## 2. Fusion에서 캠 기구 설계하기

`12. 캠 기구.f3d`를 엽니다. 프레임, 축, 핸들이 미리 준비되어 있습니다.

### 캠 만들기

![캠의 스케치](/images/lesson11/cam-sketch.jpg)

1. 적당한 평면에 스케치를 만듭니다
2. **원**을 그립니다(예: 지름 **22.5 mm**)
3. 원의 중심에 **축 구멍**을 그립니다(지름 **2 mm**)
4. 중요: **축 구멍의 위치를 중심에서 어긋나게 합니다**

::: tip 편심량과 상하 폭의 관계
축 구멍을 원의 중심에서 **얼마나 어긋나게 하는지**에 따라 상하 움직임의 폭이 정해집니다.

- 어긋난 거리의 **2배**가 상하 운동의 폭이 됩니다
- 예: 중심에서 **6.25 mm** 어긋나게 하면 → 상하 **12.5 mm**의 왕복 운동

어긋나는 거리가 클수록 움직임은 커지지만 기구에 걸리는 부하도 커집니다.
:::

5. **스케치 치수**로 구멍의 위치를 정확하게 설정합니다(예: 중심에서 **6.25 mm**)
6. 스케치를 **돌출**합니다(두께 **2.5 mm**, MDF 기준)
7. **새 구성요소**로 만들고 이름을 「캠」으로 합니다

### 캠 받침면 만들기

캠으로부터 오는 힘을 받아 내는 면은 되도록 넓게 만들어야 합니다.

1. 새 스케치에서 **정사각형**을 그립니다(예: **15 × 15 mm**, 중심에 **2 mm** 구멍)
2. **2.5 mm**로 돌출하고 **새 구성요소**로 만듭니다(이름: 「캠면」)
3. **강체 조인트**로 축봉의 끝에 붙입니다
4. 조인트 후에 어긋남이 생겼다면 마우스 오른쪽 버튼 클릭 → **조인트 편집**에서 오프셋을 미세 조정합니다(예: **-0.75 mm**)

::: warning 마찰과 축 휘어짐에 대한 대책
캠 기구에서는 캠과 종동자 사이에 마찰이 발생합니다. 실제로 제작할 때는:
- **윤활 스프레이**를 뿌립니다
- **아크릴판** 등 잘 미끄러지는 재료를 사용합니다
- 캠의 **폭을 늘립니다**(MDF를 겹칩니다)
- 캠 받침면을 **크게 합니다**(접촉 면적을 늘립니다)
- 축의 **무지지 구간을 짧게 합니다**(스페이서로 틈을 메웁니다). 축이 휘면 캠이 제대로 접촉하지 않게 됩니다
:::

### 축(종동자)의 조인트 설정

![캠 기구 조립](/images/lesson11/cam-mechanism.jpg)

종동자 봉은 위아래로만 움직일 수 있게 합니다:

1. 축과 상판을 **슬라이더 조인트**로 연결합니다
2. 방향을 **상하 방향(Y축)**으로 설정합니다
3. 이 시점에서는 아직 캠과 연동하지 않습니다

### 접선 관계로 캠의 움직임 시뮬레이션하기

![접선 관계 설정](/images/lesson11/tangent-relation.jpg)

캠의 곡면과 종동자의 면을 항상 접촉시키려면 **모션 링크가 아니라 「접선 관계」**를 사용합니다.

::: tip 왜 모션 링크로는 안 되는가
기어의 경우에는 회전 각도의 비로 연동할 수 있지만, 캠 기구에서는 「몇 도 회전하면 몇 mm 움직인다」가 일정하지 않습니다. 캠의 형상에 따라 변하기 때문에 **접선 관계**를 사용해 「항상 두 면이 접해 있다」는 구속 조건을 설정합니다.
:::

1. **조립 → 접선 관계**를 선택합니다
2. **캠의 바깥 둘레면**을 클릭합니다
3. **종동자의 캠 받침면**을 클릭합니다
4. **확인**으로 확정하면 자동으로 올바른 위치 관계가 계산됩니다

설정 후 핸들의 회전 조인트를 드래그해 돌리면 캠 받침면이 항상 캠에 접한 상태로 위아래로 움직입니다.

## 3. 요동 크랭크 기구(참고)

::: tip 참고 자료
요동 크랭크 기구는 수업 진행 상황에 따라 다룹니다. 시간 사정으로 생략하는 경우도 있지만 최종 과제에서 활용할 수도 있습니다. 완성 견본 파일이 클래스룸에 있으니 관심 있는 사람은 스스로 학습해 보세요.
:::

**요동 크랭크 기구**는 회전 운동을 요동(왕복 회전) 운동으로 변환하는 기구입니다. 캠 기구와는 다른 방식으로 왕복 운동을 구현합니다.

### 구성 부품

![요동 크랭크의 부품](/images/lesson11/crank-parts.jpg)

| 부품 | 역할 |
|------|------|
| **크랭크** | 일정한 방향으로 회전하는 입력 부품(핸들로 돌림) |
| **커넥팅 로드** | 크랭크와 로커를 잇는 링크 |
| **로커** | 일정한 각도 범위에서 요동하는 출력 부품 |
| **프레임** | 크랭크와 로커의 회전축을 고정 |

### Fusion에서 요동 크랭크 조립하기

![요동 크랭크 조립](/images/lesson11/crank-assembly.jpg)

`13. 요동 크랭크.f3d`를 엽니다. 각 부품은 이미 만들어져 있지만 조인트가 설정되어 있지 않습니다.

1. **프레임**을 고정합니다(핀 고정 권장)
2. **크랭크**를 프레임에 **회전 조인트**로 연결합니다
3. **커넥팅 로드**의 한쪽 끝을 크랭크에 **회전 조인트**로 연결합니다
4. **커넥팅 로드**의 다른 쪽 끝을 로커에 **회전 조인트**로 연결합니다
5. **로커**를 프레임에 **회전 조인트**로 연결합니다

모든 조인트가 **회전 조인트**라는 점이 요점입니다.

![요동 크랭크의 시뮬레이션](/images/lesson11/crank-simulation.jpg)

조립이 끝나면 크랭크를 드래그해 돌려 봅시다. 로커가 일정한 각도 범위에서 요동하는 것을 확인할 수 있습니다.

::: warning 링크 비율에 주의
크랭크의 길이, 커넥팅 로드의 길이, 두 축 사이의 거리의 균형이 중요합니다. 균형이 나쁘면 기구가 잠겨서 움직이지 않게 됩니다. **`13. 요동 크랭크(완성본).f3d`**와 비교해 확인해 주세요.
:::

## 4. 캠 기구와 요동 크랭크의 비교

| 특징 | 캠 기구 | 요동 크랭크 기구 |
|------|----------|-----------------|
| **출력의 움직임** | 직선 왕복(상하 운동) | 요동(왕복 회전) |
| **움직임의 자유도** | 캠 형상으로 자유롭게 설계 가능 | 링크 비율로 요동 각도를 조정 |
| **부품 수** | 적음(캠 + 종동자) | 많음(크랭크 + 로드 + 로커) |
| **매끄러움** | 캠 형상에 좌우됨 | 링크 기구이므로 비교적 매끄러움 |
| **제작 시 주의점** | 마찰 대책이 필요 | 구멍 뚫기와 핀 접합의 정밀도가 중요 |
| **가라쿠리에서의 용도** | 인형의 상하 운동, 고개 젓기 | 팔 흔들기, 발 구르기, 북 치기 |
