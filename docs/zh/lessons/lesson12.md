# 第12讲 作品制作 1：零件设计与输出

## 本讲目标

- 理解期末作业的概要与评价要点
- 设计机关作品的零件，并用 3D 打印机或激光切割机输出
- 至少输出 1 个零件，并汇报进度

---

## 关于期末作业

### 作业主题

**制作一件运用机构的机关（からくり）作品**

把至今学过的齿轮机构、凸轮机构、曲柄摇杆机构等组合起来，制作一件原创的机关作品。

## 本讲的作业内容

### 1. 把作品构想具体化

1. 决定使用哪种机构（齿轮、凸轮、曲柄摇杆等）
2. 画出完成形象的草图（手绘即可）
3. 列出所需零件的清单
4. 确定各零件的大致尺寸

::: tip 构思的要点
- 先从 **简单的结构** 出发，把「能动起来」放在第一位
- 做得过于复杂会导致组装困难
- 把机构的运动 **比拟** 成别的事物，可以提升独创性（例：齿轮的旋转 → 行星的公转）
:::

### 2. 零件的设计

1. 在 Fusion 中为各个零件建模
2. 注意零件之间的 **嵌合** 与 **连接部位** 的尺寸
3. 用 3D 打印输出时：
   - 想办法让悬垂角不超过 45°
   - 尽量减少需要支撑材料的部位
4. 用激光切割输出时：
   - 按板厚进行尺寸设计
   - 导出 DXF 文件

### 3. 零件的输出

1. 把设计好的零件导出为 `.stl`（3D 打印机）或 `.dxf`（激光切割机）
2. 按照设备的操作步骤进行输出
3. 确认输出零件的尺寸，必要时修改设计
