# 第14讲 作品的完成与视频拍摄

## 本讲目标

- 改进试作品，完成作品
- 拍摄作品的视频
- 撰写作品概要文档

---

## 本讲的作业内容

### 1. 试作品的改进

修正上次动作验证中发现的问题点。

- 如果需要重新设计、重新输出零件，请尽早着手
- 如果通过微调就能解决，可以用锉刀或钻头处理

### 2. 修整与装饰

进行提升作品完成度的收尾工作。

| 巧思 | 方法 |
|------|------|
| **表面处理** | 打磨、补土填平 |
| **涂装** | 丙烯颜料、喷漆 |
| **装饰** | 活用贴纸、胶带、布料、纸张等异材质 |
| **底座的整理** | 把底座做得整洁，确保稳定性 |

::: tip 评价要点「完成度」
表面处理、涂装、装饰、异材质运用等方面的巧思，都包含在评价的「完成度」中。请在时间允许的范围内尽量把收尾做到位。
:::

### 3. 视频的拍摄

拍摄作品运转时的视频。

1. 在 **光线明亮的地方** 拍摄
2. 使用 **三脚架或手机支架** 会更稳定，能拍到作品全貌
3. 请包含以下内容：
   - 作品的全景
   - 转动手柄、机构运转的样子
   - 特别用心之处的特写
4. 视频长度以 **30 秒〜1 分钟左右** 为参考标准

### 4. 撰写作品概要文档

制作一份包含以下内容的文档（Word 或 Google 文档等）。

- **作品名称**
- **概念**：基于怎样的构思与「比拟」创作了这件作品
- **使用的机构**：齿轮、凸轮、曲柄摇杆等
- **用心之处**：在设计、造型、收尾方面下的功夫
- **遇到的困难与解决方法**
