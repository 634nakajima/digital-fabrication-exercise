---

## 发表的流程

### 1. 作品发表

每人依次发表自己的作品。

**发表内容（每人 3〜5 分钟左右）：**

1. 介绍 **作品名称** 与概念
2. **实演**：让作品动起来展示给大家
3. 说明 **使用的机构**
4. **用心之处** 与 **遇到的困难**
5. 问答

::: tip 发表的要点
- 一边让作品运转一边讲解，更容易让人理解
- 讲一讲「为什么选择这个机构」「把它比拟成了什么」，能更好地传达独创性
- 也请分享失败与反复尝试的经历，那同样是学习的一部分
:::

### 2. 讲评

- 教师的反馈
- 同学之间的感想与评论

### 3. 课程总结

回顾整个课程，梳理在数字制造方面的收获。
