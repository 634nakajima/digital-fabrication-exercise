## 关于机构的种类

除了上一讲的齿轮机构和本讲的凸轮机构之外，还有许多可以用在机关作品中的机构。

| 机构 | 特点 |
|------|------|
| **正齿轮** | 在平行轴之间传递旋转（上一讲已学） |
| **锥齿轮（伞齿轮）** | 在直角相交的轴之间传递旋转 |
| **蜗轮蜗杆** | 可获得很大的减速比，并具有防逆转功能 |
| **齿条与齿轮** | 把旋转运动转换为直线运动 |
| **凸轮机构** | 把旋转转换为上下运动（本讲学习） |
| **曲柄滑块** | 把旋转转换为直线往复运动（活塞运动） |
| **曲柄摇杆** | 把旋转转换为摆动运动（本讲学习・参考） |

参考：[からくりすと（Karakurist）](https://karakurist.jp/) — 可以观看各种机构的动画

## 1. 什么是凸轮机构

**凸轮机构** 是把旋转运动转换为往复运动（如上下运动）的机构。广泛用于机关人偶、八音盒等。

### 凸轮机构的构成

| 零件 | 作用 |
|------|------|
| **凸轮** | 旋转的零件。形状不同，运动模式也不同 |
| **从动件（Follower）** | 沿凸轮表面运动的零件，输出上下运动 |
| **机架** | 支撑凸轮与从动件的结构体 |

### 凸轮的种类

| 凸轮形状 | 运动特点 |
|---|---|
| **圆盘凸轮（偏心凸轮）** | 平滑的上下运动。最为简单 |
| **心形凸轮** | 等速上升、等速下降。节奏均匀的运动 |
| **蛋形凸轮** | 缓慢上升、快速下降（或反之） |
| **不规则凸轮** | 可以自由设计运动，适合创作 |

## 2. 在 Fusion 中设计凸轮机构

打开 `12. 凸轮机构.f3d`。文件中已经准备好了机架、轴与手柄。

### 凸轮的创建

![凸轮的草图](/images/lesson11/cam-sketch.jpg)

1. 在合适的平面上创建草图
2. 画一个 **圆**（例：直径 **22.5 mm**）
3. 在圆心处画出 **轴孔**（直径 **2 mm**）
4. 关键点：**把轴孔的位置从圆心偏移开**

::: tip 偏心量与上下行程的关系
轴孔从圆心 **偏移多少**，决定了上下运动的行程。

- 偏移距离的 **2 倍** 就是上下运动的行程
- 例：从圆心偏移 **6.25 mm** → 上下 **12.5 mm** 的往复运动

偏移距离越大运动幅度越大，但机构承受的负荷也越大。
:::

5. 用 **草图尺寸** 精确设定孔的位置（例：距圆心 **6.25 mm**）
6. 把草图 **拉伸**（厚度 **2.5 mm**，按 MDF 计）
7. 以 **新建部件** 的方式创建，并把名称改为「凸轮」

### 凸轮承接面的制作

承受凸轮推力的面需要尽量做大。

1. 在新草图中画一个 **正方形**（例：**15 × 15 mm**，中心开 **2 mm** 的孔）
2. 拉伸 **2.5 mm**，并设为 **新建部件**（名称：「凸轮面」）
3. 用 **刚性接头** 装到轴杆的端部
4. 如果接头之后出现错位，可右键 → **编辑接头** 微调偏移量（例：**-0.75 mm**）

::: warning 摩擦与轴弯曲的对策
凸轮机构中，凸轮与从动件之间会产生摩擦。实际制作时可以：
- 涂抹 **润滑喷雾**
- 使用 **亚克力板** 等更顺滑的材料
- **增加凸轮的厚度**（叠加 MDF）
- **加大凸轮承接面**（增加接触面积）
- **缩短轴的无支撑区段**（用垫片填补间隙）。轴一旦弯曲，凸轮就无法正确接触
:::

### 轴（从动件）的接头设置

![凸轮机构的组装](/images/lesson11/cam-mechanism.jpg)

让从动件的杆只能上下运动：

1. 用 **滑块接头** 连接轴与顶板
2. 方向设为 **上下方向（Y 轴）**
3. 此时还不会与凸轮联动

### 用相切关系仿真凸轮的运动

![相切关系的设置](/images/lesson11/tangent-relation.jpg)

要让凸轮的曲面与从动件的面始终保持接触，**不能用运动链接，而要用「相切关系」**。

::: tip 为什么不能用运动链接
齿轮可以按旋转角度的比例联动，但凸轮机构中「转多少度就移动多少毫米」并不是恒定的。由于会随凸轮形状变化，所以要用 **相切关系** 来设定「两个面始终保持接触」这一约束。
:::

1. 选择 **装配 → 相切关系**
2. 点击 **凸轮的外周面**
3. 点击 **从动件的凸轮承接面**
4. 按 **确定** 后，系统会自动计算出正确的位置关系

设置完成后，拖动手柄的旋转接头进行旋转，凸轮承接面就会在始终贴合凸轮的状态下上下运动。

## 3. 曲柄摇杆机构（参考）

::: tip 参考资料
曲柄摇杆机构会根据授课进度决定是否讲解。有时会因时间关系省略，但它也可以用在期末作品中。课堂系统中提供了完成范例文件，有兴趣的同学可以自学。
:::

**曲柄摇杆机构** 是把旋转运动转换为摆动（往复旋转）运动的机构。它以与凸轮机构不同的方式实现往复运动。

### 组成零件

![曲柄摇杆的零件](/images/lesson11/crank-parts.jpg)

| 零件 | 作用 |
|------|------|
| **曲柄** | 朝固定方向旋转的输入零件（用手柄转动） |
| **连杆** | 连接曲柄与摇杆的连接件 |
| **摇杆** | 在一定角度范围内摆动的输出零件 |
| **机架** | 固定曲柄与摇杆的旋转轴 |

### 在 Fusion 中组装曲柄摇杆

![曲柄摇杆的组装](/images/lesson11/crank-assembly.jpg)

打开 `13. 曲柄摇杆.f3d`。各个零件已经做好，但还没有设置接头。

1. 固定 **机架**（推荐使用钉住功能）
2. 用 **旋转接头** 把 **曲柄** 连接到机架上
3. 用 **旋转接头** 把 **连杆** 的一端连接到曲柄上
4. 用 **旋转接头** 把 **连杆** 的另一端连接到摇杆上
5. 用 **旋转接头** 把 **摇杆** 连接到机架上

要点在于：所有接头都是 **旋转接头**。

![曲柄摇杆的仿真](/images/lesson11/crank-simulation.jpg)

组装完成后，试着拖动曲柄让它旋转。可以看到摇杆会在一定角度范围内摆动。

::: warning 注意连杆比例
曲柄的长度、连杆的长度以及两个轴之间的距离，三者的平衡非常重要。平衡不好机构就会卡死不动。请与 **`13. 曲柄摇杆（完成版）.f3d`** 对照确认。
:::

## 4. 凸轮机构与曲柄摇杆机构的比较

| 特点 | 凸轮机构 | 曲柄摇杆机构 |
|------|----------|-----------------|
| **输出的运动** | 直线往复（上下运动） | 摆动（往复旋转） |
| **运动的自由度** | 可通过凸轮形状自由设计 | 通过连杆比例调整摆动角度 |
| **零件数量** | 少（凸轮 + 从动件） | 多（曲柄 + 连杆 + 摇杆） |
| **平顺性** | 取决于凸轮形状 | 因为是连杆机构，相对平顺 |
| **制作时的注意点** | 需要做摩擦对策 | 打孔与销连接的精度很关键 |
| **在机关作品中的用途** | 人偶的上下运动、摇头 | 挥臂、踏步、打鼓 |
