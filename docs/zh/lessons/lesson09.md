## 1. 零件的部件化

### 实体与部件的区别

到目前为止我们都是通过创建 **实体（Body）** 来造型的，但要设计多个零件相互运动的机构（例如齿轮相互啮合），就必须把零件创建为 **部件（Component）**。

| | 实体 | 部件 |
|---|---|---|
| 用途 | 单个零件内部的形状 | 作为独立的零部件来处理 |
| 移动 | 与其他实体联动 | 可以单独移动、旋转 |
| 接头 | 不可使用 | 可以使用 |

::: tip 部件的形象比喻
部件类似电脑上的 **文件夹**。父部件里可以放子部件，子部件里还能放孙部件，形成层级结构，零件变多时也便于整理。
:::

### 从草图创建部件

![部件的创建](/images/lesson09/component-creation.jpg)

1. 打开 `1. 零件的部件化.f3d`
2. 点击事先准备好的草图，执行 **拉伸**（快捷键：**E**）
3. 这里很关键：把操作的下拉菜单从 **「新建实体」改为「新建部件」**
4. 把桌面板拉伸 **5 mm**，并把部件名称改为「桌面板」

### 制作桌腿（部件的复制）

和桌面板一样，从桌腿的草图以 **新建部件** 的方式拉伸（高度 **50 mm**）。

要做出 4 条桌腿需要用到 **复制**，但这里有一个重要的区别：

![部件的复制](/images/lesson09/component-copy.jpg)

| 复制方式 | 操作 | 特点 |
|---|---|---|
| **移动/复制** | 右键 → 移动/复制 → 打开「创建副本」 | 始终与原件 **同步**（修改一个，另一个也会改变） |
| **粘贴副本** | 复制 → 右键 → **粘贴新建（粘贴副本）** | 完全 **独立** 的副本（修改一个不会影响另一个） |

::: warning 注意同步复制
用「移动/复制」做出来的部件，在一个上开孔，另一个上也会开孔。需要多次使用同一零件时很方便，但如果想单独修改，请使用「粘贴新建」。
:::

## 2. 接头（刚性）

### 自下而上与自上而下的设计

| 方法 | 说明 | 适用场景 |
|---|---|---|
| **自下而上型** | 先设计各个零件，之后再组装 | 通用零件的复用、大型装配体 |
| **自上而下型** | 在整个装配体中设计各个零件 | 零件之间位置关系紧密的设计 |

本次采用自下而上的方式，先做好零件，再用 **接头** 组装。

### 用刚性接头组装桌子

打开 `2. 接头 刚性.f3d`。此时桌面板与 4 条桌腿是分离的状态。

![接头的捕捉点指定](/images/lesson09/joint-rigid-snap.jpg)

1. 选择 **装配 → 接头**
2. 先点击 **要移动的一方**（桌腿）的捕捉点
3. 再点击 **目标位置**（桌面板的角）的捕捉点
4. 确认类型为 **刚性**，按 **确定** 完成

![桌子组装完成](/images/lesson09/table-assembly.jpg)

### 捕捉点的指定技巧

- **点击面** → 捕捉到该面的中心
- **点击边** → 捕捉到边的中点
- **点击角** → 捕捉到顶点

::: tip 用 Ctrl（Mac：Cmd）键固定面
选择捕捉点时，移动鼠标可能会切换到别的面。按住 **Ctrl**（Mac：**Cmd**）键再点击面，该面的捕捉点候选就会被 **固定**，更容易选中。
:::

::: tip 「翻转」按钮
如果零件被装成了与预期相反的朝向，可以试试接头设置界面中的 **「翻转」** 按钮。
:::

### 练习：箱体的组装

打开 `3. 接头 刚性 练习.f3d`。用 6 块板组装成一个箱子。

![箱体的组装练习](/images/lesson09/box-assembly.jpg)

**组装顺序的诀窍：**
1. 先把 **左右两块板** 装到前面板与后面板上
2. 接着装 **后面的板**
3. 最后装 **上下两块板**

::: warning 注意组装顺序
如果一上来就装上下两块板，由于左右板还没装上，会很难对位。请先以前面板为基准装好左右板，再装上下板。
:::

前面板和后面板上开有方孔和圆孔。之后要在这里穿入杆件，所以组装时请注意 **让前后的孔位对齐**。

## 3. 接头（旋转・滑块）

打开 `4. 接头 旋转・滑块.f3d`。

### 旋转接头

**旋转接头** 让零件能够绕一个轴旋转。

1. 选择 **装配 → 接头**
2. 指定作为旋转轴的捕捉点
3. 把运动类型设为 **旋转**
4. 按 **确定** 完成
5. 拖动零件，它就会绕指定的轴旋转

### 滑块接头

**滑块接头** 让零件能够沿直线滑动。

1. 选择 **装配 → 接头**
2. 指定决定滑动方向的捕捉点
3. 把运动类型设为 **滑块**
4. 按 **确定** 完成

### 运动限制的设置

![滑块的运动限制](/images/lesson09/slider-motion-limit.jpg)

可以限制接头的活动范围，让零件只在预期的范围内运动。

1. 在浏览器面板或时间线上 **双击** 接头图标（或右键 → **编辑接头**）
2. 在 **运动** 选项卡中设置：
   - **最小值**：活动范围的下限（例：**-23 mm**）
   - **最大值**：活动范围的上限（例：**-4 mm**）
3. 一边用 **预览限制** 确认，一边微调数值
4. 按 **确定** 完成

::: tip 数值的微调
一开始就给出刚好合适的数值是很难的。请一边使用「预览限制」，一边一点点调整数值，让它与挡块的位置正好吻合。
:::

### 零件的固定（钉住功能）

在操作接头的过程中，有时不希望动的零件却动了。

![钉住功能](/images/lesson09/pin-fix.jpg)

- 右键点击部件 → 选择 **固定（Pin）**，该零件就会被完全固定
- 通过刚性接头与被钉住零件相连的零件也会一起被固定
- 要解除时，再次右键点击 → **解除固定**

### 练习：箱体、旋转杆、滑动杆与挡块的组装

![旋转与滑块的练习目标](/images/lesson09/rotation-slider-goal.jpg)

打开 `5. 接头 旋转・滑块 练习.f3d`，组装以下内容：

1. 用刚性接头组装 **箱体**（复习）
2. 在 **方杆** 的两端用刚性接头装上挡块（T 字形零件）
3. 用 **滑块接头** 把方杆装到箱体上，并设置运动限制
4. 在 **圆杆** 上用刚性接头装上挡块
5. 用 **旋转接头** 把圆杆装到箱体上
6. 完成后活动各个零件，确认功能是否正常

### 部件的颜色区分显示

当零件变多、难以分辨时：

点击 **实用程序 → 显示部件颜色**，就会按部件自动分配颜色。同一部件的副本颜色相同，结构上会更加一目了然。

## 4. 运动研究（Motion Study）

这是把组装完成的模型的运动 **自动播放为动画** 的功能。

![运动研究](/images/lesson09/motion-study.jpg)

1. 选择 **装配 → 运动研究**
2. 点击要做成动画的接头
3. 在时间线上 **添加点**，并输入角度或位置的数值
   - 例：给旋转接头设置 **0° → 360°**
4. 按 **播放** 按钮，运动就会以动画形式呈现
5. 用 **循环播放** 可以反复确认

::: tip 速度调整
如果播放太快，可以用速度调整滑块调慢。
:::
