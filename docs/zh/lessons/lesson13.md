# 第13讲 作品制作 2：试作品的组装

## 本讲目标

- 把输出好的零件组装成试作品
- 验证机构能否正常运转
- 找出问题点，制定改进计划

---

## 本讲的作业内容

### 1. 零件的确认与修整

1. 检查上次输出的零件
2. 根据需要进行以下后处理：
   - **去毛刺**：用美工刀或锉刀去除多余部分
   - **去除支撑材料**：3D 打印件的情况
   - **孔的调整**：轴孔过紧时用钻头或锉刀微调
   - **表面打磨**：用锉刀把表面打磨光滑

### 2. 试作品的组装

1. 按设计好的顺序组装零件
2. 一边组装一边确认以下几点：
   - 零件之间能否好好嵌合
   - 旋转轴是否转动顺畅
   - 齿轮和凸轮是否正确啮合／接触
   - 机架（底座）的强度是否足够

::: tip 组装不顺利时
- 孔太紧 → 用钻头或锉刀扩孔
- 孔太松 → 用胶水固定，或者重新设计、重新输出零件
- 轴晃动 → 重新检查轴承部位的精度
- 齿轮啮合不上 → 确认中心距与齿隙（背隙）
:::

### 3. 动作验证

1. 转动手柄等，让机构运转起来
2. 确认以下内容：
   - 是否达成了预期的运动
   - 运转是否顺畅（有没有卡顿）
   - 耐久性是否有问题

### 4. 改进计划

整理动作验证中发现的问题点，制定到下次上课为止的改进计划。
